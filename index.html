01 / 背景

CAEの検討サイクルが長い

鋳造解析は「形状受領 → メッシュ作成 → 条件設定 → 計算 → 評価」の流れで進みます。特に計算に時間がかかり、条件を振るたびにこのサイクルを回すため、設計・製造への回答が遅れがちでした。

condition_03.datShift-JIS / 手で読めない

まず 「確認できる」「集められる」 状態にすることが先決。

04 / 取り組み② データ確認ツール

解析条件を一目で確認する

CAEの条件ファイルを読み込み、部品名を統一名にマッピングし、熱伝達係数などの条件を一覧・グラフで表示します。マッピングできない部品や値の外れを一目で見つけ、学習に使う前にデータの不備を潰せます。

JP

Shift-JIS の条件ファイルを読込

文字化けなく、そのまま可視化

⇄

部品名を統一名へマッピング

表記ゆれを吸収し、ケース間で比較可能に

h

熱伝達係数を一覧・グラフ表示

設定漏れ・外れ値をその場で発見

PS

Python 不要で誰でも使える

PowerShell ＋ 単体HTML、配布するだけ

05 / 取り組み③ データ集約ツール

散らばったデータを学習データへ集約

散らばった解析ケースを収集し、確認ツールのチェックを通ったものだけを登録。バージョン管理したうえで学習用データセットとして書き出します。下のアニメーションの赤い点が不備のあるデータで、確認の段階で除外されます。
