# サロゲート開発の取り組み

鋳造CAEのサロゲートモデル開発で見えた課題と、学習データを確認・集約するツール開発についての報告資料です。

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | Web版（読み物）。背景・モデル検討・課題・確認ツール・集約ツール・結論・今後を1ページで説明 |
| `slides/index.html` | 5分プレゼン用スライド（全8枚、1920×1080 を画面に合わせて拡縮） |

ビルド不要の静的HTMLです。ブラウザで `index.html` を開けば動きます（フォントのみ Google Fonts を参照）。

## スライドの操作

| キー | 動作 |
| --- | --- |
| `→` / `Space` / クリック | 次へ（アニメーションを1段ずつ） |
| `←` / 画面左側クリック | 前へ |
| `T` | 5分タイマー（スライドごとの目安つき） |
| `N` | 話す内容（スピーカーノート） |
| `F` | 全画面 |
| `1`〜`8` | 指定のスライドへ移動 |
| `?` | ヘルプ |

`slides/#s3` のように URL の末尾で開くスライドを指定できます。
